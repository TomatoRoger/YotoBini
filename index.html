          How copies work

          1. Yoto app: playlist → Link to a card → official MYO / orange card.
          2. Read the MYO card here, then write the link to a blank card.
          3. A copy only plays after each player has downloaded the playlist. Play it once on the player (from the card or from the Yoto app, with the player on Wi-Fi), then leave the player charging. To check: Yoto app → Settings → player → Audio Download Status.
          4. After you edit a playlist, copies need no rewrite, but each player has to download the new tracks again.

          If writing fails

          “Not supported” usually means the blank isn't NDEF-formatted (common with MIFARE Ultralight EV1). Fix it in NFC Tools: Other → Advanced NFC commands, send:

          A2:03:E1:10:06:00,A2:04:03:04:D8:00,A2:05:00:00:FE:00

          Never lock a card (make read-only).

          One-time setup

          1. Host this file on HTTPS (e.g. GitHub Pages). Sign-in and NFC don't work from a file:// page.
          2. At dashboard.yoto.dev, create an app with client type Public.
          3. Redirect URI:
          4. Tick and save the scopes user:content:manage, user:content:view, user:icons:manage and offline_access. All four are needed: the API checks each one by name.
          5. Put the Client ID into CONFIG.clientId at the top of the script, so the grandparent never sees this screen. You can also paste it below for testing.
